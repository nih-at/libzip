libzip has been packaged for various operating systems and
distributions. We know of at least the following. Please let us know
if you know about more:

* [AIX Open Source Packages](http://www.perzl.org/aix/index.php?n=Main.Libzip)
* [Android NDK repackaging](https://github.com/julienr/libzip-android) (for libzip 1.0.1)
* [Android NDK repackaging](https://github.com/dec1/libzip-android) (for libzip 1.2.0)
* [Archlinux](http://www.archlinux.org/packages/extra/x86_64/libzip/)
* [Conan](https://conan.io/center/libzip)
* [Cydia](http://moreinfo.thebigboss.org/moreinfo/depiction.php?file=libzipData)
* [Cygwin-Ports](http://cygwin-ports.cvs.sourceforge.net/viewvc/cygwin-ports/ports/libs/libzip/)
* [Debian](https://tracker.debian.org/pkg/libzip)
* [Fedora](https://apps.fedoraproject.org/packages/libzip)
* [Fedora](https://apps.fedoraproject.org/packages/mingw-libzip) (mingw-libzip)
* [FreeBSD](http://www.freshports.org/archivers/libzip/)
* [Gentoo](http://packages.gentoo.org/package/dev-libs/libzip)
* [HAIKU ports](http://bb.haikuports.org/haikuports/src/79f735cb8bdd869bc0b0e350a956f2a7bda6e58b/dev-libs/libzip?at=master)
* [HP-UX Porting & Archiving Centre](http://hpux.connect.org.uk/hppd/hpux/Misc/libzip-0.10.1/)
* [MacPorts](https://ports.macports.org/port/libzip/details/)
* [OpenMandriva](https://abf.openmandriva.org/openmandriva/libzip/build_lists) (cooker)
* [NetBSD](http://pkgsrc.se/archivers/libzip)
* [NixOS](https://hydra.nixos.org/job/nixpkgs/trunk/libzip.x86_64-linux)
* [OpenBSD](ftp://ftp.openbsd.com/ports/archivers/libzip/)
* [OS4Depot](http://os4depot.net/?function=showfile&amp;file=development/library/misc/libzip.lha) (Amiga OS4)
* [Pardus](http://packages.pardus.org.tr/info/playground/source/libzip.html)
* [Rudix](http://rudix.org/packages/libzip.html)
* [The T2 Project](http://www.t2-project.org/packages/libzip.html)
* [Ubuntu](https://launchpad.net/ubuntu/+source/libzip)
* [various RPM-based distributions](http://rpmfind.net/linux/rpm2html/search.php?query=libzip) (CentOS, Mageia, OpenSUSE/SUSE)
* [MINGW-packages](https://github.com/Alexpux/MINGW-packages/tree/master/mingw-w64-libzip) (Windows)
* [VC++ Packaging Tool Package (vcpkg)](https://github.com/Microsoft/vcpkg/tree/master/ports/libzip) (Windows)
